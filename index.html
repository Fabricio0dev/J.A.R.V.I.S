JARVIS

O acesso exige login com Google. O Client ID é público (não é segredo): crie um em Google Cloud Console > APIs e serviços > Credenciais > ID do cliente OAuth (Aplicativo da Web) e adicione a URL onde este arquivo está hospedado em “Origens JavaScript autorizadas”.
O login identifica sua conta e separa seus dados locais. Ele não dá acesso a Gmail, Drive ou Agenda: isso só é pedido quando você usa o recurso.

Conta

Voz

O reconhecimento de voz usa o serviço do navegador (no Chrome/Edge, o áudio é enviado ao fornecedor do navegador). O microfone só fica ativo quando o botão 🎙 está aceso. Voz masculina depende das vozes instaladas no seu sistema.

Central de inteligências

Se um provedor bloquear chamadas do navegador (CORS), informe um proxy seu. Ele recebe POST {url, headers, body} e repete a chamada, devolvendo a resposta original.
Chaves ficam só na memória desta aba. Para guardá-las, defina uma senha: elas são criptografadas (AES-GCM) no seu navegador.

Memória e aprendizado

Diga “lembre que …” para salvar. Apenas o que está aqui é usado nas respostas. Nada treina os modelos externos; a memória é só sua, neste navegador.
