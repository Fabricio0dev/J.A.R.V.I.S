Conta

Voz

O reconhecimento de voz usa o serviço do navegador (no Chrome/Edge, o áudio é enviado ao fornecedor do navegador). O microfone só fica ativo quando o botão 🎙 está aceso. Voz masculina depende das vozes instaladas no seu sistema.

Central de inteligências

As chamadas às IAs (OpenAI, Gemini, Claude, Perplexity) vão sempre direto à API oficial, sem proxy. Este campo é opcional e só afeta a busca de notícias e da Wikipédia: informe um proxy público, por exemplo https://corsproxy.io/? (a URL original é colada depois dele; se terminar em “=”, é codificada). Vazio: o Jarvis usa o AllOrigins automaticamente. Suas chaves nunca passam por proxy.
Nenhuma alteração pendente.
As chaves ficam salvas neste navegador, criptografadas (AES-GCM) com uma chave do próprio navegador. Quem usar este mesmo navegador/perfil poderá usá-las; não use em computador compartilhado.
Cofre com senha (opcional, avançado)

Memória e aprendizado

Diga “lembre que …” para salvar. Apenas o que está aqui é usado nas respostas. Nada treina os modelos externos; a memória é só sua, neste navegador.
